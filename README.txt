PORTOFOLIO EBEN SUDIANTO SITUMORANG

CARA MEMBUKA
1. Ekstrak file ZIP.
2. Buka folder eben_portfolio_final.
3. Klik dua kali index.html untuk membuka di browser.

CARA MENAMBAHKAN FOTO
1. Simpan foto pribadi dengan nama foto-eben.jpg.
2. Letakkan file itu di folder images.
3. Muat ulang index.html. Foto akan muncul otomatis.
Foto belum disertakan karena belum ada file foto yang diunggah.

CARA EDIT
Buka index.html dengan Visual Studio Code atau editor teks.
style.css mengatur tampilan; script.js mengatur navigasi.
Semua detail kontak menggunakan data yang diberikan pengguna.
Nama instansi ditulis sebagai Dinas Kependudukan dan Pencatatan Sipil Kota Medan berdasarkan informasi pengguna; periksa ejaan nama resmi sebelum dipublikasikan.

CATATAN
- Website statis, tidak memerlukan server/database untuk dibuka.
- Font Google memerlukan koneksi internet; font cadangan tetap tersedia.
- Sebelum dipublikasikan, pastikan semua informasi dan sertifikat benar.
